# Recent-window research

This is an original ForgeX research workflow, not a copy of the upstream Last 30 Days tool.

1. Clarify the time window and topic; default to the last 30 days only when appropriate.
2. Search for dated primary sources, release notes, repository commits, official announcements, and relevant community discussion.
3. Separate publication date from event date.
4. Corroborate major claims with more than one independent source when feasible.
5. Distinguish facts, community sentiment, and speculation.
6. Summarize what changed, why it matters, and what remains uncertain.
7. Link the underlying sources. Never invent citations, engagement metrics, or recency.
8. If search tooling cannot filter reliably by date, disclose the limitation.

Optional upstream reference: https://github.com/mvanhorn/last30days
